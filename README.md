# Replication Project For Fuchs 2026

## Project Overview

This repository contains materials, data-processing scripts, and statistical analyses for a replication of Fuchs et al. (2026) examining sentence comprehension in heritage Spanish-English bilinguals and Spanish second-language (L2) learners. Data collection was implemented in jsPsych and analyzed in R. 

The single-task picture-matching study examined Spanish sentence comprehension by asking participants to listen to Reduced Relative (RR), Subject Relative (SR), and Object Relative (OR) sentences and select the image that best matched the sentence they heard.


## Analysis Workflow

1. The preprocessing script assigns each participant a unique identifier based on the subject_id field generated by jsPsych.
2. Preprocessed data are saved to the data/ directory.
3. The analysis script imports the preprocessed data.
4. Participants are classified as Heritage Speakers (HS) or Late L2 Learners (L2).
5. Exclusion criteria are applied.
6. Trial-level accuracy and reaction-time data are cleaned.
7. Logistic mixed-effects models are fit to evaluate the effects of Relative Clause (RC) type and participant group.


## Participant Classification

Participants are classified from questionnaire responses according to age of acquisition of Spanish:

- Heritage Speaker (HS): Spanish acquired at age 6 or earlier.
- Late L2 Learner (L2): Spanish acquired at age 7 or later.


## Exclusion Criteria

Participants are excluded if any of the following criteria are met:

1. Spanish is reported as both the first-acquired language and the dominant language.
2. Accuracy on Reduced Relative (RR) trials is below chance (< 50%).
3. L2 participants report less than one year of Spanish coursework.
4. Less than two attention-check items are answered correctly.


For reaction-time analyses:

- Responses faster than 150 ms are removed.
- Responses more than 2.5 standard deviations from a participant's mean within a relative-clause condition are removed.


## Data Dictionary

| Variable | Description |
|-----------|------------|
| subject_id | Participant identifier automatically assigned by SONA.
| sound_check_passed | Audio check result. 1 = audio played correctly, 0 = audio failed. |
| Age | Participant age in years. |
| Gender | Self-reported gender. |
| trial | Trial number within the experiment. |
| block | Experimental block number (4 blocks of 30 audio stimuli). |
| structure | Sentence type: Reduced Relative (RR), Subject Relative (SR), or Object Relative (OR). |
| pair | Identifier for the image pair presented on that trial. |
| audio | Audio stimulus presented on the trial. |
| pic_left | Image displayed on the left side of the screen. |
| pic_right | Image displayed on the right side of the screen. |
| correct_response | Correct response for the trial (left or right arrow key). |
| correct | Accuracy outcome. 1 = correct response, 0 = incorrect response. |
| rt | Reaction time measured from audio onset to participant response (milliseconds). |
| attention_check_passed | Attention-check outcome. 1 = passed, 0 = failed. |
| task | Task type (e.g., test trial, attention check, questionnaire). |

## Software

Analyses were conducted in R using:

- lme4

- stringr

## Reproducibility

All preprocessing files, exclusion criterias, and analyses are documented in the write-up R scripts and Quarto report. Running the preprocessing script followed by the analysis script should reproduce all reported results.
